# Roadmap

LocalAgentUI is an experimental project. This roadmap describes areas of exploration, not delivery commitments.

## Current foundation

- Local React/Vite UI and FastAPI backend.
- Main Agent and Specialist Agent orchestration.
- Agent, Capability and Tool management foundations.
- Proposal/Project lifecycle and execution authorisation concepts.
- Prompt/context construction and local SQLite persistence.
- Workspace and Artifact Registry foundations.

## Areas to improve

- Improve end-to-end reliability of Proposal, Project and task workflows.
- Strengthen governance checks and execution evidence across all tool paths.
- Improve automated tests for agent dispatch, permissions, approvals and artifacts.
- Simplify first-run setup and add a user-facing environment diagnostics page.
- Improve provider abstraction and model configuration while retaining a local-first default.
- Refine visual configuration for non-technical users.
- Improve cross-platform compatibility only after dedicated testing.

## Longer-term exploration

- Agent lifecycle, evaluation and capability development.
- Better observability, audit history and recovery from failed tasks.
- More complete documentation and extension interfaces.

Priorities may change as the project is tested on different hardware and with different local models.
