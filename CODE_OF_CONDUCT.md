# Code of Conduct

Participants in this project are expected to communicate respectfully and constructively.

Examples of unacceptable behaviour include harassment, discriminatory language, personal attacks, deliberate intimidation, publishing private information without permission, and sustained disruptive conduct.

Project maintainers may edit, reject or remove contributions that violate these expectations. If you experience or observe unacceptable behaviour, contact the repository owner privately through the contact method listed on the repository profile.
